# 日语歌曲逐句跟读学习工具 MVP 规格

## Problem Statement

用户希望通过自己拥有的日语歌曲音频和带时间戳的 LRC 歌词，进行逐句、可重复、可变速的听读与跟读练习。普通音乐播放器虽然可以播放歌曲和显示歌词，但难以稳定地限定在某一句歌词的时间范围内循环，也不会记录逐句学习位置和练习进度。通用语言学习工具又通常缺少针对日语歌曲的假名标注、罗马音和中文翻译展示。

用户需要一个能够部署在个人 NAS 上、通过手机和电脑浏览器访问的单用户学习工具。歌曲、歌词、录音和学习数据应保存在 NAS 本地，不依赖云服务、在线曲库、账户系统或自动转录服务。

## Solution

构建一个运行在单个 Docker 部署单元中的响应式 Web 应用。用户从歌曲库上传自己的音频文件和对应的逐句时间戳 LRC 文件；服务端将媒体文件保存在 NAS 挂载目录，并使用 SQLite 保存歌曲元数据、解析后的歌词句子、逐句练习状态、最后练习位置、播放偏好和录音元数据。

用户进入歌曲练习页后，可以选择任意歌词句子，按该句时间范围播放或持续循环，调整播放速度、循环间隔以及句首/句尾缓冲。页面同时展示日文原句、汉字假名标注、可切换的罗马音和中文翻译。用户可以录制自己的跟读、立即回放，并将需要保留的录音存入 NAS。首页始终为歌曲库，并显示每首歌的学习进度及继续练习入口。

应用以学习效率为视觉重点，支持手机和电脑浏览器。MVP 不需要互联网连接；但 Docker 服务本身仍需通过局域网或其他私有网络连接访问。

## Implementation Decisions

- 产品形态为单用户、NAS 托管、响应式 Web 学习工具；手机和电脑访问同一个服务端学习库。
- 应用使用 Docker 部署，并将至少三个持久化位置映射至 NAS：媒体文件、录音文件、SQLite 数据及备份工作目录。实现可以合并物理目录，但数据职责必须清晰。
- SQLite 是服务端唯一结构化数据源，不能把关键进度只保存在浏览器本地存储中。
- 媒体二进制文件保存在 NAS 文件系统；SQLite 只记录稳定的内部标识、相对路径、元数据、大小和内容类型，不存储大型音频 BLOB。
- MVP 的逻辑领域对象至少包括：歌曲、歌词句、练习进度、播放偏好和录音。
- 歌曲记录包括标题、可选歌手、媒体元数据、创建时间、最后练习时间、最后练习歌词句及总体进度摘要。
- 歌词句记录包括所属歌曲、原始顺序、开始时间、由下一句开始时间推导的结束时间、日文原句、假名、罗马音和中文翻译。
- 最后一句的结束时间使用音频总时长；如果无法得到总时长，则该歌曲不能完成导入。
- LRC 是必需输入。MVP 只接受具有逐句时间戳且至少包含一个有效歌词句的 LRC，不提供纯文本歌词转时间轴、自动转录或图形化 LRC 编辑器。
- LRC 校验保持最小但不能完全省略：必须拒绝无法解析、没有时间戳、时间戳超出音频、时间戳不递增或无法形成有效句子区间的输入。错误信息应指出失败原因。
- 上传采用先验证、后提交的原子流程：只有音频和 LRC 均验证成功，歌曲、歌词及媒体文件才成为可见数据；失败时清理未提交的临时文件。
- 音频通过支持 Range 请求的服务端接口传输，以便浏览器可以跳转和重复播放大文件，而无需每次完整下载。
- 逐句播放区间为 `max(0, 句首时间 - 前缓冲)` 到 `min(音频时长, 句尾时间 + 后缓冲)`。
- 循环引擎支持单次播放和无限循环。每轮到达结束边界后暂停用户设置的间隔，再从区间起点继续。
- 循环间隔、播放速度、前缓冲和后缓冲均可调整；具体默认值可在实现阶段选择，但必须设有安全范围并持久化。
- 变速播放使用浏览器原生媒体能力并保持音高；可用档位至少覆盖慢速、原速，界面也可采用安全范围内的连续调节。
- 用户主动选择新句、切歌、停止循环或离开练习页时，必须取消任何尚未触发的下一轮循环定时器，避免后台继续播放。
- 练习进度至少记录歌词句是否练习过、累计练习次数和最近练习时间。完成一次有效的句子播放或录音后更新，而不是仅凭选中句子更新。
- 每首歌记录最后练习的歌词句，首页仍为歌曲库，但提供“继续练习”入口。
- 多设备不是独立同步系统；所有设备天然共享同一 SQLite 数据。MVP 不处理同一时间多设备修改造成的高级冲突，仅保证单次写入的事务一致性。
- 录音通过浏览器麦克风 API 采集。未保存录音属于临时数据；用户明确保存后才上传至 NAS 并建立数据库记录。
- 录音记录关联歌曲与歌词句，并保存创建时间、时长、格式、文件位置等元数据。
- 日语辅助文本在导入流程中形成并持久化。原始 LRC 只保证日文原句；假名、罗马音和中文翻译可以由上传时附带的数据或后续手动数据导入提供。由于 MVP 完全离线，不能假设存在云端翻译或语言模型。
- “给所有汉字标注假名”是必须达到的用户体验，但自动标注技术和纠错方式尚未由现有讨论确定。实现应允许存储最终标注结果，并将自动生成能力封装为可替换组件。
- 罗马音支持显示开关；中文翻译在练习界面显示。MVP 不包含逐词词典或语法解释。
- ZIP 备份包含数据库快照、媒体、已保存录音、原始 LRC 和带版本号的清单。恢复应先完整验证，再以事务或替换式流程提交，失败不得破坏现有数据。
- 应用不需要账户系统。因为没有身份认证，默认部署边界应是家庭局域网或用户管理的私有 VPN；不得把无认证实例直接暴露在公网。
- 应用运行时不依赖第三方网络服务、在线歌曲目录、歌词搜索或云同步。
- 删除歌曲属于级联删除操作，覆盖关联歌词句、进度和录音；必须二次确认，并在数据库与文件系统之间提供失败恢复策略。
- 界面以学习效率为主要视觉方向：歌曲库负责选择与进度概览，练习页突出当前句、辅助文本、播放循环控制和录音回放。
- MVP 应提供可通过 Docker 健康检查调用的服务状态端点，并验证数据库可读写及持久化目录可用。

## Testing Decisions

- 主要测试边界采用一个最高层的端到端用户流程：从浏览器上传音频和 LRC，经真实 HTTP 服务写入临时 NAS 挂载目录与临时 SQLite，再进入练习页控制媒体、保存进度和录音，最后导出并恢复 ZIP。该边界验证用户可观察行为，而不是组件内部实现。
- 端到端测试覆盖桌面和移动视口，但共享同一组用户流程断言，避免按设备复制业务测试。
- 上传流程测试有效 LRC 成功导入，以及无时间戳、乱序时间戳、超出音频时长和不支持音频的可理解失败；失败后不得留下可见歌曲、孤立数据库记录或永久临时文件。
- 播放测试观察媒体请求、跳转位置、区间终止、循环间隔和下一轮起点；不测试定时器或播放器内部状态变量。
- 句子边界测试覆盖第一句、普通中间句和最后一句，并验证前后缓冲不会越过零或音频总时长。
- 练习进度测试通过真实的有效播放或录音行为触发，然后刷新页面并从另一浏览器上下文读取结果，以验证服务端持久化和共享状态。
- 录音测试使用浏览器提供的确定性测试媒体流，验证权限拒绝、开始、停止、临时回放、保存、重新加载和删除等外部行为。
- 备份恢复测试从一个已包含歌曲、进度和录音的实例导出 ZIP，再恢复到空实例，并从 UI 验证学习库等价；损坏或版本不兼容的备份必须保持原数据不变。
- Docker 验收测试启动容器并挂载临时持久化目录，写入数据后重建容器，再验证数据仍可访问。
- 响应式验收覆盖关键控件在窄屏可见、可触达、无水平溢出，以及桌面键盘快捷键的用户效果。
- 测试只断言外部行为、持久化结果和 API 契约，不断言框架组件树、私有函数调用次数、SQLite 查询文本或内部定时器实现。
- 当前项目没有代码或既有测试，因此不存在可复用的测试先例。新测试应优先围绕上述单一端到端边界建立；仅对难以通过端到端精确覆盖的 LRC 时间解析和 ZIP 清单兼容性增加少量契约测试。

## Out of Scope

- 自动从音频转录日语歌词或生成 LRC。
- 在线搜索、下载、抓取或分发歌曲、歌词和封面。
- 内置流媒体服务或第三方音乐账户集成。
- 图形化 LRC 时间轴编辑器和复杂歌词纠错工具。
- 逐词时间戳、卡拉 OK 式逐词高亮。
- 自动发音评分、音高曲线比较、节奏评分或 AI 反馈。
- 逐词词典、形态分析、语法解释和自动生词卡。
- Anki 式间隔重复或自动复习计划。
- 多用户、账户、权限角色和公开分享。
- 独立的跨设备同步协议、离线设备编辑后合并以及冲突解决。
- 公网匿名部署支持。
- 原生 iOS、Android 或桌面客户端。
- 云端备份与第三方存储同步。

## Further Notes

- 当前目录只有概念笔记，没有代码、Git 元数据、ADR、领域术语表或测试基础设施。本规格中的领域词汇因此直接来自用户讨论。
- 现有需求中，“完全离线”指不依赖外部互联网服务；浏览器仍需通过局域网或私有 VPN 访问 NAS 上的 Docker 服务。
- 现有需求中，“不需要跨设备同步”解释为不构建额外同步机制；手机和电脑访问同一个服务端数据库时仍然共享状态。
- 用户表示这是个人学习用途。产品仍应避免提供在线受版权内容获取或分发能力，但不需要在 MVP 中构建内容版权管理系统。
- 假名、罗马音和中文翻译的数据来源尚未最终确定。为保证完全离线和结果可校正，数据模型与导入接口必须允许保存显式结果，不能把运行时云服务作为必需依赖。
- MVP 的部署暴露范围尚未被用户明确确认。鉴于不做登录，本规格采用局域网或私有 VPN 作为安全默认值。
- 本地 `issues/` 目录作为该项目的 issue tracker；本规格标记为 `ready-for-agent`。
